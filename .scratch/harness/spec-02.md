# EPIC 02 — Runtime por execução

## Objetivo

Cada execução da pipeline tem identidade (`run_id`), diretório isolado e trilha de eventos. Duas runs não sobrescrevem estado uma da outra. Compatibilidade com `outputs/` mantida (cópia do artefato mais recente).

## Fora de escopo

Canonical Spec, claims, validadores, loop Devin.
